# 🎮 坦克大战 · Tank Battle

一个纯 **HTML / CSS / JavaScript** 实现的经典《坦克大战》小游戏，使用 HTML5 Canvas 渲染，**零依赖**，无需安装任何东西，双击打开即玩。

## ✨ 特性

- 🕹️ 经典玩法：驾驶坦克、消灭敌人、保卫基地
- 🧱 可破坏的砖墙、坚不可摧的钢墙、水域与树林掩护
- 🤖 敌人 AI：自动寻路、追击玩家、随机开火
- 💥 粒子爆炸特效、屏幕震动、关卡切换闪白
- 🔊 Web Audio 合成音效（无需任何音频素材文件）
- 🏆 关卡系统、分数、生命与道具奖励
- 📱 自适应布局，键盘与触屏方向键均可操作

## 🎯 玩法

保卫地图底部的 **金色基地**，消灭所有敌人即可过关。基地或你的坦克全部阵亡则游戏结束。

### 操作键位

| 按键 | 功能 |
| ---- | ---- |
| `W A S D` / `↑ ← ↓ →` | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |

## 🚀 运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：双击 index.html
# 方式二：本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 🗺️ 地图元素

| 图例 | 含义 |
| ---- | ---- |
| 🧱 砖墙 | 可被子弹摧毁 |
| ⬜ 钢墙 | 无法摧毁 |
| 🌊 水域 | 无法通行 |
| 🌲 树林 | 可通行，遮挡坦克 |
| ▲ 基地 | 需保卫的目标 |

## 🛠️ 技术实现

- 单文件实现，所有代码内嵌于 `index.html`
- Canvas 2D 渲染 + `requestAnimationFrame` 游戏循环
- 网格碰撞检测与滑动修正
- 基于 Web Audio API 的程序化音效合成
